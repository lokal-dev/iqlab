# Product

## Register

product

## Users
Casual Indonesian Muslim learner (pemula/intermediate). Arabic level: knows surahs by heart, recites imperfectly ("lidah Indo"). Goal is to verify memory or identify an ayah.

## Product Purpose
Interactive Quran Laboratory (iq.lab) to identify Quran verses by voice recitation or audio upload and return the top 3 matching verses with color-coded Tajweed rendering.

## Brand Personality
Empathetic, non-judgmental, modern. Acts as an automated supportive peer, not a strict examiner.

## Anti-references
Strict/critical examination apps, generic plain fonts, heavy login/auth gates, complex dashboards.

## Design Principles
1. Empathy First: Pronunciation feedback is supportive, not penalizing.
2. Speed and Clarity: Return matches instantly with clean typing indicators and clear confidence scores.
3. Authentic Arabic Typography: Render classical Uthmani script with color-coded Tajweed indicators.
4. Seamless Local Flow: Use localStorage to keep user context private and client-side without registration.

## Accessibility & Inclusion
Clean high-contrast dark mode text, clear visual feedback for audio recording states, and support for custom Arabic fonts.
